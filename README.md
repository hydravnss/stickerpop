# stickerpop
Extension SillyTavern : affiche le sprite des Character Expressions comme un sticker.

- Le sticker reste affiché tant que vous ne le masquez pas (aucun minuteur).
- Masquage : double toucher (défaut), simple toucher, ou « jamais : permanent » (Extensions > StickerPop).
- Un petit bouton 🖼 réaffiche un sticker masqué ; un nouveau sticker est toujours affiché.
